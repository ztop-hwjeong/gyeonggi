# Motion

[디자인 개요](../DESIGN.md) · [시스템 구조](system.md) · [기초 스타일](foundations.md) · [컴포넌트](components.md) · [사용 패턴](patterns.md)

조작은 즉각적으로 반응하고, 나타나는 내용은 짧고 부드럽게 자리 잡는다. 모션은 내용의 위치와 처리 결과를 설명하는 역할을 가진다. 단순한 전환을 없애 화면이 딱딱하게 느껴지게 하거나, 장식을 위해 반복 동작을 추가하지 않는다.

## Shared Tokens

| 역할 토큰 | 값 | 의미 |
|---|---|---|
| `motion.duration.press` | 150ms | 누름의 색상·작은 축소 |
| `motion.duration.menu` | 200ms | 메뉴·드롭다운·토스트 등장 |
| `motion.duration.enter` | 250ms | 대화·보조 패널 등장 |
| `motion.duration.exit` | 150ms | 메뉴·패널·토스트 퇴장 |
| `motion.duration.message` | 150ms | 새 메시지의 한 번의 등장 |
| `motion.easing.enter` | `cubic-bezier(0, 0, 0.15, 1)` | 빠르게 반응한 뒤 부드럽게 감속 |
| `motion.easing.exit` | `cubic-bezier(0.35, 0, 1, 1)` | 지체하지 않고 사라지는 움직임 |
| `motion.scale.pressed` | 0.98 | 구조가 허용하는 독립 버튼의 작은 누름 |
| `motion.distance.control` | 4px | 작은 떠 있는 요소·새 메시지의 이동 |
| `motion.distance.panel` | 8px | 큰 보조 패널의 이동 |

px은 기본 글자 크기 16px 기준이며 거리 토큰은 rem을 사용한다. 별도 지연 시간은 기본으로 추가하지 않는다. 색상·축소를 함께 사용할 때는 같은 시점과 150ms로 하나의 반응처럼 전달한다.

## Component Behavior

| 대상 | 시작과 종료 | 적용 범위 |
|---|---|---|
| 독립 버튼·예시 질문 | 누르는 동안 색상 변화와 0.98 축소, 놓으면 원래 상태 | 비활성·로딩에는 누름 동작 없음. 연결된 표의 행·입력 필드 전체를 축소하지 않음 |
| 연결형 드롭다운 | 실행 상자에 붙은 위치에서 불투명도만 전환. 등장 200ms·퇴장 150ms | 목록을 따로 이동해 연결 면이 벌어지지 않게 유지 |
| 독립 메뉴 | 투명·아래 4px → 제자리·불투명. 퇴장은 역방향 | 실행 버튼의 위치는 안정적으로 유지 |
| 대화·보조 패널 | 투명·아래 8px → 제자리·불투명 | 패널 본체에 한 번 적용. 내부 제목·문단을 순차적으로 다시 등장시키지 않음 |
| 새 메시지 | 투명·아래 4px → 제자리·불투명 | 새 메시지가 추가될 때 한 번. 스트리밍 글자마다 재시작하지 않음 |
| 토스트 | 투명·아래 4px → 제자리·불투명, 닫을 때 역방향 | 표시 위치·유지 시간·접근성 안내는 알림 패턴을 따름 |
| 선택 아이콘 | Regular ↔ 같은 계열 Fill | 상태는 즉시 전달. 임의의 회전·튀어 오름·SVG 형태 변형을 추가하지 않음 |
| 차트·표 결과 갱신 | 실제 결과가 준비되면 값과 라벨 함께 변경 | 값이 없는 상태를 가짜 카운트업으로 채우지 않음. 첫 화면의 모든 막대를 일괄 등장시키지 않음 |

패널이 닫히면 본문이 사용하던 공간을 회수한다. 본문의 폭 재배치를 애니메이션할 때는 글자와 차트가 찌그러지지 않는지 확인하고, 구현상 보장할 수 없으면 패널의 퇴장 후 즉시 재배치한다. 읽는 중인 본문 전체를 축소하는 방식으로 부드러움을 흉내 내지 않는다.

## Interruption and Focus

- 같은 요소를 빠르게 열고 닫으면 이전 전환을 취소하고 마지막 요청한 상태로 끝낸다. 이전 종료 콜백이 다시 열린 내용을 숨기지 않게 한다.
- 닫기를 누르면 즉시 접근성 상태와 조작 가능 상태를 닫힘으로 바꾸고 포커스를 실행 위치에 돌려준다. 퇴장 효과가 끝날 때까지 닫히는 내용이 입력을 받지 않게 한다.
- 열릴 때는 실제로 조작 가능한 상태가 된 뒤 키보드 탐색을 연결한다. 메뉴·선택 목록의 포커스 정책은 각 컴포넌트 규격을 따른다.
- 등장 효과가 실행될 때마다 화면을 강제로 스크롤하지 않는다. 대화의 이전 내용을 읽고 있으면 위치를 유지한다.
- 응답 중단은 텍스트 생성을 즉시 멈춘다. 퇴장 효과가 끝날 때까지 요청 취소를 늦추지 않는다.

## Reduced Motion

`prefers-reduced-motion: reduce`에서는 이동·축소·반복 효과를 제거하고, 내용을 즉시 최종 위치와 상태로 표시한다. 기능과 안내는 유지한다. 누름은 색상으로 전달하며, 로딩 표시를 멈추더라도 처리 중이라는 텍스트·접근성 상태는 남긴다.

설정이 사용 중에 바뀌어도 실행 중인 움직임을 중단하고 마지막 요청 상태로 정리한다. 처음부터 투명한 콘텐츠가 남거나 닫힌 영역에 포커스가 갇히지 않게 한다.

## Implementation Boundary

모션 구현은 **CSS + Web Animations API**로 통일한다. 색상·누름·아이콘 방향 전환은 CSS, 등장·퇴장처럼 상태 수명과 연결되는 전환은 Web Animations API를 사용하는 공통 모션 함수로 처리한다. 같은 동작을 화면마다 개별 구현하지 않는다.

별도 애니메이션 라이브러리는 도입하지 않는다. 앱의 UI 프레임워크와 관계없이 공통 모션 계층에서 시간·거리·가속도·취소·동작 줄이기를 관리한다. 화면 코드는 역할 이름과 열림·닫힘 상태를 전달하고, 세부 수치를 다시 정의하지 않는다.

## Reference and Validation

- [당근 SEED Motion](https://seed-design.io/foundations/motion): 작은 피드백과 큰 전환, 등장·퇴장 가속도의 구분
- [당근 SEED Feedback](https://seed-design.io/foundations/feedback): 색상과 축소의 같은 시작·시간, 동작 줄이기에서 남는 피드백
- [토스 인터랙션](https://toss.tech/article/interaction): 다음 행동과 처리 상태를 이해시키는 움직임

국내 서비스의 공개 관행을 참고해 비즈렌즈의 역할별 수치를 정한 것이다. 특정 모션이나 라이브러리를 한국인 전체가 선호한다는 주장으로 해석하지 않는다. 기본·반복 조작·키보드·빠른 재개폐·동작 줄이기에서 같은 최종 상태에 도달하는지 실제 화면으로 확인한다.
