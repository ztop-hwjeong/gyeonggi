# Components

[디자인 개요](../DESIGN.md) · [시스템 구조](system.md) · [기초 스타일](foundations.md) · [사용 패턴](patterns.md)

개별 UI의 크기·형태·상태를 정의한다. 색상·서체·간격은 기초 스타일을 따르고, 어떤 상황에 선택하고 조합하는지는 사용 패턴을 따른다.

## Shared Sizes

**기본 크기는 M**이다. 아래 값은 시안의 개별 치수를 복제한 것이 아니라 화면 일관성을 위해 정한 공통 기준이다. XS·S·M·L 외의 중간 크기를 화면별로 추가하지 않는다. 토큰은 `size.control.{xs|s|m|l}.{height|padding-x|font-size|icon|gap}`으로 구분한다.

| 크기 | 높이 | 좌우 여백 각각 | 글자 | 아이콘 | 아이콘·글자 간격 | 사용 기준 |
|---|---|---|---|---|---|---|
| XS | 28px | 8px | 12px | 12px | 4px | 표 안의 짧은 보조 동작 |
| S | 32px | 12px | 14px | 16px | 4px | 밀도가 높은 도구 모음과 필터 |
| M | 40px | 16px | 14px | 16px | 8px | 기본 버튼과 일반 폼 |
| L | 48px | 20px | 16px | 20px | 8px | 큰 입력 영역과 터치 중심 조작 |

높이는 테두리를 포함한 기본 최소 높이다. 글자 확대나 긴 번역 문구가 들어오면 잘라내지 않고 높이를 늘린다. 너비는 내용에 맞추되, 같은 행에서 동일한 역할의 컨트롤은 같은 크기 단계를 사용한다. 글자 행간은 1.5를 사용한다.

## Buttons

- 기본 버튼은 M, 글자 굵기는 500이다. 주요·보조·텍스트·위험 버튼 모두 같은 크기표를 사용한다.
- 버튼 위계는 색상과 채움으로 구분한다. 주요 동작이라는 이유만으로 버튼 크기나 글자 굵기를 올리지 않는다.
- 아이콘 전용 버튼의 너비와 높이는 해당 단계의 높이로 맞춘다. 아이콘 크기는 크기표를 그대로 따른다.
- 일반 동작은 Phosphor Regular, 선택·켜짐은 같은 계열 Fill을 사용한다. 모양만으로 상태를 전달하지 않고 선택 배경·글자·접근성 상태를 함께 제공한다.
- 일반 버튼은 한 줄의 짧은 동작명으로 작성한다. 로딩 중에는 같은 아이콘 영역에 표시하고 기존 너비를 유지한다.
- ‘처리’, ‘실행’처럼 막연한 이름보다 사용자가 얻는 결과를 드러내는 동작명을 사용한다. 기본 버튼을 모두 외곽선 스타일로 만들지 않는다.
- 기본·호버·누름·포커스·비활성·로딩 상태에서 테두리 두께와 여백을 바꾸지 않는다. 비활성·로딩 중에는 중복 실행을 막는다.

| 위계 | 표현 | 사용 조건 |
|---|---|---|
| 주요 | `action.primary` 배경 + `action.foreground` 글자 | 현재 작업을 완료하거나 다음으로 진행하는 핵심 동작 |
| 보조 | 옅은 중립색 `action.secondary-background` + `action.secondary-foreground` 글자 | 주요 동작과 함께 제공하는 취소·이전·부가 동작 |
| 낮은 강조 | 투명 배경 + `action.ghost-foreground` 글자 | 반복 행의 보조 동작, 더보기 등 |
| 위험 | `action.danger` 배경 + `action.foreground` 글자 | 삭제 등 손실을 일으키는 최종 확인 동작 |

위계별 조합·배치·문구는 [동작 위계](patterns.md#action-hierarchy)를 따른다.

## Inputs and Selects

- 입력창과 선택 상자는 S·M·L을 사용하고 기본은 M이다. XS 입력창은 만들지 않는다.
- 높이·글자·아이콘·좌우 여백은 공통 크기표를 따른다. 입력 내용은 400, 라벨은 500을 사용한다.
- 같은 행의 입력창·선택 상자·버튼은 같은 크기 단계를 적용해 높이를 맞춘다.
- 오류 상태에서도 크기와 테두리 두께를 유지한다. 오류는 상태색과 별도 설명으로 표시한다.
- 여러 줄 입력은 M의 글자·좌우 여백을 적용하고 최소 높이 96px, 위아래 여백 12px을 사용한다.
- 텍스트 입력·검색·선택 상자·여러 줄 입력은 아래 공통 상태 규칙을 사용한다. 기본 모서리는 S다. 대화 입력처럼 버튼을 포함한 복합 입력은 M 모서리를 사용하되 표면·경계·상태 규칙은 동일하다.
- 입력창·라벨·도움말은 하나의 필드로 묶고, 필드 사이는 16px 또는 묶음이 달라지면 24px로 띄운다. 조회 영역의 배경색에 따라 입력 스타일을 별도로 덮어쓰지 않는다.
- 도움말과 오류 설명은 14px로 읽히게 표시한다. ‘미입력 상태’ 같은 관리 용어보다 ‘제목을 입력해주세요’처럼 다음 행동을 설명한다.

| 상태 | 입력 계열 공통 표현 |
|---|---|
| 기본 | 흰색 `field.background`, 본문색 `field.foreground`, 1px `field.border` 경계 |
| 호버 | 흰 표면 유지, 경계만 `field.border-hover`로 강화 |
| 포커스 | 표면·크기 유지, 공통 `focus.ring` 외곽선 표시. 복합 입력은 전체 외곽에 한 번 표시 |
| 목록 열림 | 흰 표면 유지, 실행 상자와 목록을 연결. 키보드 포커스는 연결된 전체 영역에 표시 |
| 오류 | 흰 표면 유지, 오류 경계와 14px 설명 제공. 호버로 오류 경계를 덮지 않음 |
| 비활성 | `action.disabled-background`·`action.disabled-foreground`, 조작 차단 |

회색 보조 버튼은 실행, 흰 입력은 값 입력이라는 역할 차이다. 색상 변경은 같은 역할의 부품 전체에 적용하며, 한 선택 상자만 예외로 만들지 않는다.

### Select Popup

- 닫힌 선택 상자는 입력 계열의 공통 크기·표면·경계·모서리·상태 규칙을 따른다. 오른쪽에 일관된 펼침 아이콘을 두고, 열림은 목록과 화살표 방향으로 표시한다.
- 펼친 목록은 실행 상자와 간격 없이 이어지는 하나의 선택 영역으로 표현한다. 같은 폭·흰 표면을 사용하고 전체 외곽은 S 모서리와 하나의 약한 그림자로 감싼다. 연결된 면의 모서리는 직선으로 맞추고 내부 구분선으로 현재 값과 목록을 나눈다. 화면 밖으로 나가면 같은 원칙으로 위쪽에 연결하거나 높이를 제한한다.
- 열렸을 때 입력 상자에만 별도의 포커스 외곽선을 겹치지 않는다. 키보드 포커스는 실행 상자와 목록을 함께 감싸는 하나의 외곽선으로 표시한다. 값과 옵션의 글자 시작선을 맞춘다.
- 항목은 최소 높이 40px, 좌우 여백 12px, S 모서리로 둔다. 터치 환경에서는 조작 대상을 최소 44px로 확보한다.
- 호버·키보드 탐색은 옅은 선택 배경으로, 확정된 값은 블루 체크와 기본 글자색으로 표시한다. 항목 전체를 진한 블루로 채우지 않는다.
- 열기·선택·방향키 탐색·Home/End 이동·Escape 닫기·Tab 이탈을 지원하고, 닫힌 후에는 실행 위치에서 자연스럽게 탐색을 이어간다. 선택 상자와 목록·라벨의 관계를 접근성 정보로 제공한다.

라벨·검증·오류 처리의 사용 기준은 [입력과 검증](patterns.md#input-and-validation)을 따른다.

## Supporting Controls

- 체크박스와 라디오의 표시 크기는 16px, 문구는 14px, 문구와의 간격은 8px로 고정한다. 문구를 포함한 행 전체를 클릭 대상으로 둔다.
- 배지는 높이 24px, 좌우 여백 8px, 글자 12px, 모서리 XS를 사용한다. 배지 안의 아이콘은 12px이다.
- 배지는 짧은 분류를 묶어 표시해야 할 때만 사용하며 기본은 중립색이다. 일반 진행 상태는 배지 틀 없이 본문 텍스트로 표시한다. 완료·검토 중이라는 이유만으로 그린·앰버를 배정하지 않는다.
- 탭의 좌우 여백은 16px을 사용한다. 탭 그룹 안에서는 같은 위계와 크기를 유지한다.
- 본문 주요 탭은 M 높이에 16px·600, 도구 안의 보조 탭은 S 높이에 14px·500을 사용한다. 같은 위계에서 크기를 섞지 않는다. 활성 탭은 글자와 밑줄로, 보기 모드 선택은 분할 선택의 옅은 바탕으로 구분한다.
- 터치 환경의 모든 조작 대상은 최소 44×44px을 확보한다. 작은 컨트롤은 조작 영역을 넓히거나 L을 사용하고, 조작 영역끼리 겹치지 않게 배치한다.

## Tables

- 표의 기본 행 최소 높이는 48px, 밀집형은 40px이다. 셀 좌우 여백은 16px, 위아래 여백은 12px을 기본으로 한다. 밀집형은 위아래 여백 8px을 사용한다. 여러 줄 내용과 글자 확대 시 행은 늘어난다.
- 텍스트는 왼쪽, 수치는 오른쪽으로 정렬한다. 정렬 가능한 열은 조작 가능 여부와 현재 방향을 드러내고, 선택·호버·정렬 상태를 다른 표현으로 구분한다.
- 행 전체 클릭과 행 안의 버튼을 겹치는 동작으로 만들지 않는다. 행 선택은 체크박스로 명확히 표시하고 일괄 동작은 선택 개수와 함께 제공한다.

표·목록·카드·차트의 선택은 [정보 표현](patterns.md#information-and-data)을 따른다.

## Navigation and Content Rows

- 읽기 목록은 한 행에 하나의 진입 동작을 둔다. 제목과 발행처·날짜를 한 클릭 영역으로 묶고 별도 보기 버튼이나 수집 상태를 기본 행에 추가하지 않는다.
- 내용을 열면 제목·발행 정보·내용을 연속해서 읽을 수 있게 한다. ‘원문’, ‘본문’, ‘확보 여부’를 구획 제목으로 나누지 않는다.

- PC 탐색 메뉴는 16px, 항목 최소 높이 44px, S 모서리로 둔다. 현재 위치는 옅은 블루 배경과 진한 글자로 구분하며 불필요한 아이콘을 항목마다 붙이지 않는다.
- 내용 행은 제목과 주요 값을 먼저 읽히게 하고, 설명은 아래·동작은 오른쪽에 둔다. 독립 내용의 제목은 16px·600, 설명과 일반 속성은 14px을 사용한다.
- 속성 목록은 왼쪽 이름·오른쪽 값 또는 이름 다음 값의 반복 행으로 정리한다. 설명 전체를 12px 주석 한 줄로 압축하지 않는다.
- 현재 위치를 바꾸는 행에는 오른쪽 방향 아이콘을 사용할 수 있다. 값 선택의 아래 방향 아이콘, 영역 펼치기, 페이지 이동을 같은 동작처럼 보이게 만들지 않는다.

## Filters and Detail Areas

- 여러 조회 조건은 `surface.subtle` 바탕과 M 모서리의 한 영역으로 묶고 내부 여백은 24px을 사용한다. 조건마다 카드를 만들지 않는다. 좁은 화면에서는 내부 여백 16px, 한 열 배치를 사용한다.
- 적용 조건을 해제하는 Chip은 S 컨트롤의 32px 높이·14px 글자·S 모서리를 사용한다. 읽기 전용 분류 배지와 형태·동작을 구분한다.
- 결과 도구는 건수 왼쪽·정렬과 다운로드 오른쪽으로 배치한다. 조회 조건을 입력하는 도구와 결과를 조작하는 도구를 한 줄에 뒤섞지 않는다.
- 보조 상세는 실제 비교가 필요할 때만 별도 영역으로 제공한다. 제목·닫기·대상 정보를 갖추고, 작은 설명문과 펼치기를 모든 항목에 반복하지 않는다.

## Common States

호버는 조작 가능성, 포커스는 현재 키보드 위치, 선택은 현재 값, 로딩은 처리 중임을 뜻한다. 이 상태를 서로 대신 사용하지 않는다.

컴포넌트에 해당하는 기본·호버·누름·포커스·선택·비활성·로딩·오류 상태를 구분한다. 해당 동작이 없는 컴포넌트에 불필요한 상태를 만들지 않는다. 상태가 바뀌어도 크기와 정렬은 유지한다.

독립 버튼의 누름, 메뉴·선택 목록의 등장과 퇴장, 동작 줄이기는 [모션 규격](motion.md)을 따른다. 닫힘의 조작 상태와 포커스는 즉시 정리하고 시각적 퇴장만 짧게 이어간다. 빠른 재개폐가 최종 선택을 되돌리지 않도록 한다.
