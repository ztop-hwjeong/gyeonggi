# 수집 구현 기준

- 기사 AI 분석은 수집 이후 Prefect에서 한 건씩 독립 실행한다. LangChain과 공식 OpenAI 클라이언트를 사용하며, 모델 입력은 기사 제목·본문으로 제한한다. 출력은 `tags: list[str]`, 최종 논조 `sentiment`(긍정·중립·부정), 논조 혼재 여부 `mixed_sentiment`, 최종 판단의 짧은 근거 `sentiment_reason`으로 구성한다. 인용·태그 설명·별도 후보·중복 키워드는 생성하지 않는다.
- 논조가 혼재해도 분석 대상에 대한 기사의 주된 평가를 기준으로 최종 논조 하나를 정한다. 기사 전재 관계는 기사끼리만 분석하며, 서로 다른 언론사의 기사를 하나로 합치지 않는다.
- 발행 일자만 확인된 자료에 시각을 만들어 넣지 않는다. 네이버 제공 시각과 원문 발행·수정 시각, 수집 시각을 구분해 보존한다.
- 기사 식별자·내용 해시·모델·실제 프롬프트 원문과 함께 분석 결과·실패 이력을 보존한다. 주제 병합·제외·집계·보고서 출력은 백엔드 책임으로 유지한다.
- 자동 생성한 제외 주제명 목록을 모델에 전달하지 않는다. 제외는 사람의 명시적 결정으로 관리한다.
- 기사 분석에 임의의 분당 처리량·한 번에 한 건 같은 속도 제한을 추가하지 않는다. 기사별 독립 실행을 유지한다.
- 분석 요청 자체를 차단하지 않고 캐시된 분석 응답을 재사용한다. 실제 프롬프트 원문을 보존하고 원문과 연결되지 않은 임의의 프롬프트 버전을 만들지 않는다.
- Prefect 작업은 Dishka 스코프에서 필요한 서비스를 가져오고, DB 저장소 객체를 작업 인자로 전달하지 않는다. 분석 저장소와 응답 캐시는 SQLAlchemy ORM/Core를 사용한다.

- 브라우저가 필요 없는 HTTP 수집은 `curl_cffi`의 Chromium impersonation을 기본으로 사용한다. User-Agent만 별도로 꾸미지 않고 해당 프로필의 기본 헤더와 TLS·HTTP 설정을 함께 사용한다. 다른 전송 방식은 소스별 요구가 확인된 경우에만 명시적으로 선택한다.
- HTTP 전송, 소스별 요청·응답 해석, 정규화, 저장, Prefect 흐름, worker 운영의 책임을 분리한다. 실행 환경별 의존성을 하나로 합치지 않는다.
- 요청 속도 제한은 같은 소스의 작업이 공유한다. 접근 제한이나 로그인 요구를 0건으로 처리하지 않는다. 기사 상세의 명시적 순서는 `curl_cffi` 원문 → 실제 Edge 탭의 `fetch()` → 기사 이동 후 렌더링 문서 → 빅카인즈 상세 API다. 렌더링 DOM은 원본 HTTP 응답과 구분해 저장한다. 인증 요구·429·Retry-After 응답은 같은 언론사에 브라우저로 반복 요청하지 않는다.
- 빅카인즈 목록 수집과 언론사 원문 상세 수집은 별도 흐름으로 관리한다. 목록의 요약을 원문 본문으로 취급하지 않고 소스 ID·원문 URL·수집 경위를 보존한다.
- 기사 상세의 HTML·JSON 응답 바이트는 RustFS에 보존한다. PostgreSQL에는 원본 객체 위치·해시·크기, 추출 결과와 언론사별 adaptive 특성·변경 이력을 저장한다. 검증에 실패한 추출은 adaptive 기록을 갱신하지 않는다.
- 언론사 본문 구조의 수동 점검은 수집 기사 동일성 검증과 구분한다. 출처·canonical 기사 ID·제목·본문 요소를 독립적으로 확인한 구조 기록은 검증 방식과 기사 대조 미확인 여부를 명시한다. 이 기록을 사용하더라도 수집 시 제목·요약 검증을 생략하지 않는다.
- 네이버 목록은 NAVER API HUB 명세를 사용한다. 검색어 OR 병합, 채널·검색식별 커서, 공통 요청 간격·일일 예산을 적용한다. 페이지 상한·오류·반복 페이지에서는 커서를 전진시키지 않는다. 최초 커서는 최신 첫 페이지를 기준으로 하며 과거 자료의 전량 수집으로 표시하지 않는다.
- 네이버 증분 수집은 최신순으로 조회한다. 이전 커서의 모든 ID와 겹침 구간 또는 검색 결과 끝을 확인해야 완료 처리한다. 날짜 경계만으로 커서를 전진시키지 않는다. 날짜 누락 글도 저장하고 누락 건수를 기록하며, 날짜 누락·역순에서는 날짜 판정을 중단한다. 작성일 없는 채널에는 날짜를 만들어 넣지 않는다.
